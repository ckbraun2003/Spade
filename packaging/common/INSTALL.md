# Install and uninstall

## Install

1. Get the installer file from the folder you were given. Its name starts with **Spade-Editor** and ends with **setup.exe**.
2. Double-click it.
3. If Windows shows a blue box saying "Windows protected your PC", click **More info**, then **Run anyway**. (This test release is not signed with a publisher certificate yet.)
4. Read the licence and click **Next**. You do not need to type a password or say yes to an administrator prompt: Spade Editor installs for you only.
5. Keep the install folder it suggests, and click **Next**, then **Install**.
6. When it says it has finished, click **Finish**.

When the install is done you have two entries in the **Start menu** (press the Windows key and type "Spade"):

- **Spade Editor**: the editor. This is where you place drones and objects, fly, and run the airflow.
- **Spade Drone Box**: a single drone on a test stand, to learn the controls and see the numbers.

You also get a **Spade User Guide** shortcut in the same Start-menu folder. It opens this guide. You get a Spade Editor icon on the desktop too.

## Start it

1. Press the Windows key, type **Spade Editor** and press **Enter**.
2. A window opens with the editor.

To see the version, click **Help**, then **About Spade Editor**. To open the user guide from the editor, click **Help**, then **User Guide**.

## Uninstall

1. Press the Windows key and type **Add or remove programs**, then press **Enter**.
2. Find **Spade Editor** in the list, click it, and click **Uninstall**.
3. Follow the steps and click **Finish**.

The Start-menu entries and the desktop icon go away with it. Scenes you saved in your own folders are not touched.

## If something goes wrong: the log

Spade Editor writes a log of what it did. If the program closes by itself or says something you do not understand, the log is the first place to look.

1. Press **Windows key + R**, paste `%LOCALAPPDATA%\Spade\logs` and press **Enter**.
2. The newest file in the folder is the log of the last time you ran the program.
