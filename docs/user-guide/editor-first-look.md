# The editor: a first look

## Open it

1. Press the **Windows key**, type **Spade Editor** and press **Enter**.
2. The editor opens on a scene called **hover**: one small drone on a flat grey ground.

![The editor when it opens](images/03_editor.png)

The window has five parts:

| Part | Where | What it is for |
|---|---|---|
| **Toolbar** | top | Run, Run air, Pause, Step, Undo, Redo, the Move and Rotate tools, Snap, the View list, Save, File and Help. The name of the scene is on the right. A star after the name (for example `hover.scene.yaml *`) means you have changes you have not saved. |
| **Hierarchy** | left | The list of what is in the scene. Click a name to select it. |
| **3D view** | middle | The scene itself. |
| **Inspector** | right | The details of whatever is selected, and messages from the editor. |
| **Library** | bottom | Drones and objects you can place. |

## Move the camera

1. Hold the **right mouse button** on the 3D view and drag: the camera goes around.
2. Turn the **mouse wheel**: the camera comes nearer or goes further.
3. Hold the right mouse button and press <kbd>W</kbd>, <kbd>A</kbd>, <kbd>S</kbd>, <kbd>D</kbd> to move sideways and forward, and <kbd>Q</kbd> and <kbd>E</kbd> to go down and up.
4. Click an object, then press <kbd>F</kbd>: the camera frames it.

## Open another scene

1. Click **File** (top right of the toolbar).
2. Under **Scenes**, click a name, for example **gate**. The scene opens.

![The File menu with the scene list](images/editor_picker.png)

You can also type the path of a scene file into **Scene file** and click **Open**. **Save As** (in the same menu) saves your scene under the path you typed there.

## Help

1. Click **Help**, next to **File** on the toolbar.
2. Click **User Guide** to open this guide, or **About Spade Editor** to see the version.

## Keys to know

| Key | What it does |
|---|---|
| <kbd>F</kbd> | Frame the selected object |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Remove the selected object |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate the selected object |
| <kbd>W</kbd>, <kbd>E</kbd> | Choose the Move tool, the Rotate tool (when the right mouse button is not held) |
| <kbd>F1</kbd> | Hide or show the small status box in the 3D view's bottom-left corner. Click **Controls** in it to see the key list. |
| <kbd>F2</kbd> | Put the panels back where they started |
| <kbd>Esc</kbd> | Close the window. It does not ask about unsaved changes. |
