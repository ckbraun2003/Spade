# Airflow reference data (spec §11.1)

This directory holds every validation case's reference data, with its provenance. Test/Docs reviews each file like a golden before its case's first run. A change to one needs a named cause (`TD-2`).

| Case | File | Source | Method |
|---|---|---|---|
| C0, the Taylor–Green vortex | none. The initial field is closed form: `u = sin x cos y cos z`, `v = −cos x sin y cos z`, `w = 0` | Brachet et al. (1983), J. Fluid Mech. 130 | V1 reports the numerics' own dissipation; DNS data enter at V3 |
| C1, the lid-driven cavity | `ghia1982_cavity.hpp` (Re 100 and 400) | Ghia, Ghia & Shin (1982), J. Comput. Phys. 48, 387–411, doi:10.1016/0021-9991(82)90058-4: Table I (p. 398) and Table II (p. 399) | Read from a scan of the published pages and checked against the scan's OCR layer. Cross-checked with two independent reproductions (the ivan-pi gists; Oceananigans.jl), which agree in every value and coordinate. The Uppsala thesis's 0.05188 (Table II, point 65, Re 400) is a misreading. Point 117, Re 400 (−0.23827) is kept as printed, a suspected typo in the original. Compared by machine with that reading: 102 values, no difference. Re 1000 is added, scan-verified, when V2 needs it |
| C8, the hovering actuator disc | none. Closed form: `v_h = √(T / 2ρA)`; on the axis at `z` below the disc, `v = v_h (1 + z / √(z² + R²))`. Since 2026-10-22 C8 reads the mean over the faces within 0.5R of the axis, 2R below: momentum theory's slipstream velocity is uniform across a station, so the reference is the same 7.5777 m/s. The vortex-cylinder model's mean over those faces is 7.5909 (`docs/design/test-docs/2026-10-22-c8-spread.md`) | Momentum theory; Leishman, *Principles of Helicopter Aerodynamics*, 2nd ed. (2006), ch. 2; this repo's `engine/vehicles/rotor_wake.hpp` §1 | Formula |
| C8q, the reference quad's rotor 0 alone, in the quad's case | none. Banded: rotor 0 alone, its neighbours pushing nothing, with its own torque. C8's closed form: `v_ref = v_h (1 + 2/√5)` 2R below its hub, where `v_h = √(T / 2ρπR²)` and `T = k_T ω²`, the model's rotor row's static thrust coefficient (the rigid-body path's thrust, independent of the disc conversion) at the run's rotor speed; band [0.9, 1.1] on window means, the ensemble's mean and its worst run. The measure is the mean downward velocity over a 0.5R disc centred 2R below the hub, normal to its axis. Momentum theory's slipstream velocity is uniform across a station, so the reference is the axis value; the vortex-cylinder model's mean over that disc is 1.0017 times it (Physics' Biot–Savart sum). The four rotors together: each rotor's ratio is report only, as their wakes' interaction and the open box's response to four times the flux, not separated, with no closed-form reference (the four-wake reference is the demonstration plan's measured-data case, item 10, `2f29a32`); the symmetry band, the four within 10% of their mean, stays. Changed on 2026-10-22, before the banded run (`docs/design/test-docs/2026-10-19-end-goal-checks.md` §5) | As C8's | Formula |

`records/` holds the validation records: one file per case, appended to by each run, never edited. Each record is a fenced `text` block in the shape `docs/design/test-docs/01-verification.md` defines.
